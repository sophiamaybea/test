# New Dance Pack Template

Copy this folder concept for every new performance.

## Required workflow

1. Analyze the source performance and identify the usable choreography window.
2. Extract timing, movement phrases, levels, facing, support changes and key poses.
3. Strip source-performer identity from the reconstruction.
4. Apply the target identity and wardrobe locks.
5. Create a frame index at the chosen stop-motion FPS.
6. Create one unique renderer prompt for every frame.
7. Upload large data files and visual references to a dedicated Google Drive folder.
8. Fill in `assets.template.json` with those links.
9. Render sequentially.
10. Onion-skin every new frame against the previous approved frame.

The final pack must stand alone without requiring the original source video.
